# Nutrition & BMI Analyzer App

A dynamic nutrition and BMI analyzer web application featuring a dynamic BMI calculator and food analysis tools.

## Features
- **BMI Calculator:** Calculate Body Mass Index dynamically.
- **Food Analyzer:** Analyze nutritional content of meal items.
- **Interactive UI:** Built using clean HTML, CSS, and modern JavaScript.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
